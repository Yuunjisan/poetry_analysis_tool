The code must be run in an environment with cuda, pytorch, transformers >= 4.43.0 and customtkinter. The code uses the pretrained llama-3.2-1B-Instruct model which requires the user to create a huggingface account and request access via the following link: [link](https://huggingface.co/meta-llama/Llama-3.2-1B-Instruct). It may take about an hour for your request to be processed. When you get access you will need to authenticate yourself in your environment, how to do that can be found in the following link: [link](https://huggingface.co/docs/huggingface_hub/en/guides/cli#huggingface-cli-login).
